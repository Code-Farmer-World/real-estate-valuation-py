# 設計：回填樹林住宅三份書表

> 格位座標全部是 2026-09-12 用 `openpyxl` 實測量出來的，不是從 PDF 版面推測。
> 量測工具：`/tmp/dump_xlsx.py`（dump 整張）、`/tmp/probe_rows.py`（細看某幾列的
> 欄位與合併範圍）。若範本更換，先重新量測再改程式。

---

## 1. 資料流

```
表3 事實 JSON（人工核對，標註來源頁碼）
   │  kernel/fixtures/shulin_survey_facts.json
   ↓
kernel/src/compute.py
   ├─ classify()  每個細項的量測值 → 優劣等級（附依據）
   ├─ lookup()    (比準地等級, 標的等級) → 修正百分比（附依據）
   └─ 新增：group_subtotals() 與 build_table5_1()
   ↓
xlsxform/
   ├─ layout.py   格位對映（純資料，本文件第 3 節的機器可讀版本）
   ├─ fill.py     決定每一格填什麼
   ├─ formulas.py 活版的 Excel 公式字串
   └─ write.py    用 openpyxl 寫入範本副本
   ↓
輸出三個 xlsx（表3 那份含四張工作表），各自有活版與定版兩種
```

⚠️ **不是合併成單一檔案。** `openpyxl` 的 `copy_worksheet()` 不能跨工作簿，
三份範本要併成一個檔案就得逐格重建格式，那會失真。同檔案內複製沒問題
（實測表3 範本複製後 188 個合併格、欄寬、列高、列印版面全部一致），
所以四張表3 放在表3 那個檔案裡。

`xlsxform/` 不 import `kernel/`，計算結果由 CLI 以參數注入，比照 `pdfform/`
的既有相依方向。

## 2. 判斷與運算的分界線

這條線決定哪些數字寫成值、哪些寫成公式。

| 類型 | 誰做 | 寫進 xlsx 的形式 | 理由 |
| --- | --- | --- | --- |
| 優劣等級判定 | `kernel.classify()` | 數值 | 要翻基準表級距，Excel 做不到，而且要能講依據 |
| 修正百分比查表 | `kernel.lookup()` | 數值 | 要查 5×5 矩陣，同上 |
| 群組小計 | 兩邊都算 | 活版公式／定版數值 | 機械加總，但要與引擎交叉驗證 |
| 總修正數 | 兩邊都算 | 活版公式／定版數值 | 同上 |
| 試算價格 | 兩邊都算 | 活版公式／定版數值 | 個別因素填入後要能自動更新 |
| 絕對值加總 | 兩邊都算 | 活版公式／定版數值 | 同上 |
| 比較標的權重 | `kernel.similarity_and_weights()` | 數值（兩版都是） | 依作業手冊 p.57 分級，含排序判斷，不是純算術 |
| 比準地比較價格 | 兩邊都算 | 活版公式／定版數值 | 加權平均 |

權重刻意不寫成 Excel 公式。它需要「絕對值加總由小到大排序後分級」的判斷
（3 件時 50%／30%／20%），而且打平時作業手冊沒有規定，需要人工介入。
寫成公式會把這個判斷藏起來。

## 4. Excel 公式（活版）

以下用比較標的1 舉例，標的2 把欄換成 `J`／`K`／`M`，標的3 換成 `M`／`O`／`Q`／`R`。

### 4.1 表5-1

```
群組小計（第 11 列，土地使用管制，排除 6、7、8 三列）
    G11 = =SUM(G5,G9,G10)

群組小計（第 18 列，交通運輸，連續範圍）
    G18 = =SUM(G12:G17)

其餘小計同理：G24=SUM(G19:G23)、G26=G25、G33=SUM(G27:G32)、
              G37=SUM(G34:G36)、G39=G38、G41=G40

總修正數（第 42 列）
    G42 = =SUM(G11,G18,G24,G26,G33,G37,G39,G41)
```

### 4.2 表4

```
區域因素調整百分率（跨表參照表5-1 的總修正數）
    J8  = ='表5-1'!G42

個別因素合計
    G29 = =SUM(J9:J28)

調整百分率絕對值加總
    G30 = =ABS(J8)+SUMPRODUCT(ABS(J9:J28))

試算價格
    G31 = =ROUND(G7*(1+J8)*(1+G29),0)

比準地比較價格（加權平均，權重在 I31／M31／Q31）
    G32 = =ROUND(G31*I31+K31*M31+O31*Q31,0)
```

百分比欄位用 Excel 的百分比格式儲存實際小數（`0.235` 顯示為 `23.50%`），
不要存成字串 `"23.50%"`，否則公式無法運算。範本原本在小計列印了「％」符號
在 `G11`、`J11`、`M11` 等位置，寫入時要確認那是儲存格的一部分還是相鄰格，
避免覆寫掉。

⚠️ `openpyxl` 寫入公式後檔案裡不會有 cached value。用 `openpyxl` 讀回來會拿到
公式字串而不是數字，要在 Excel、Numbers 或 Google Sheets 開啟才會計算。
這是活版與定版必須並存的原因。

## 5. 定版的數值

全部由 `kernel` 算出，個別因素以 0 計。

```
表5-1  總修正數     標的1 +23.50%   標的2 +14.75%   標的3 +14.75%
表4    J8/N8/R8     同上（跨表抄填的那一格，命題點名的錯誤來源）
表4    G29/K29/O29  個別因素合計 0（前提）
表4    G30/K30/O30  絕對值加總 23.50% / 19.75% / 19.75%
表4    G31/K31/O31  試算價格 170,337 / 161,577 / 206,885 元/㎡
表4    I31/M31/Q31  權重（暫定，因為標的2 與標的3 打平）
表4    G32          比準地比較價格 = 加權平均後四捨五入至個位
表4    D34          全案備註寫明個別因素前提
```

`D34` 的備註文字：

> 本表個別因素（項目7至25）依表4 註記由地價查估單位辦理，題目未提供宗地個別
> 條件資料。本表區域因素調整百分率由影響地價區域因素評價基準明細表計算，
> 試算價格以個別因素0計，比較標的權重依調整百分率絕對值加總暫定，
> 個別因素填入後須重新計算。

## 6. 模組結構

```
xlsxform/
├── __init__.py
├── layout.py     格位對映常數（第 3 節的機器可讀版本），純資料無邏輯
├── fill.py       決定每一格填什麼，輸入是計算結果 dict
├── formulas.py   活版的公式字串產生器
├── write.py      用 openpyxl 開範本副本並寫入，處理合併格與工作表複製
├── cli.py        一行指令的入口
└── tests/
```

`kernel/src/compute.py` 新增：

```python
def group_subtotals(rs, grades_bench, grades_comp, *, exclude=()) -> dict[str, Decimal]
def build_table5_1(rs, facts_by_segment, *, exclude=()) -> Table5_1Result
```

`Table5_1Result` 是 frozen dataclass，含 116 格等級、87 格修正率、24 格小計、
3 格總修正數，每一格帶 `reason`（依據字串）與 `source_page`。

## 7. 寫入範本時的注意事項

1. **合併格只能寫主格。** 寫從格會拋 `AttributeError: 'MergedCell' object has no
   attribute 'value'`。主格是合併範圍左上角那一格。
2. **複製工作表產生四張表3。** `openpyxl` 的 `copy_worksheet()` 不能跨檔案，
   同一個工作簿內可以。但它不會複製列高、欄寬以外的某些格式，複製後要檢查。
   如果失真，替代方案是開四次範本各寫一張，再用 `zipfile` 層級合併，
   或直接產出四個檔案（那與使用者的決定不符，只在複製失真時才考慮）。
3. **不要動 23 張隱藏工作表。** 它們是舊範本樣例，但屬於官方檔案的一部分。
4. **`data_only=False` 載入**（預設值），否則會丟掉範本裡既有的公式與文字。
5. 官方範本沒有任何有效公式，所以不必擔心覆寫掉原有計算邏輯。
